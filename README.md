# Colab Notebook Practice

This repository is set up for practicing Google Colab notebooks and GitHub collaboration workflows.

## Included notebooks
- `notebooks/intro.ipynb` — starter notebook with Python examples
- `notebooks/data-analysis.ipynb` — simple data analysis example using pandas and matplotlib

## Open in Colab
You can open any notebook directly in Google Colab by uploading it to Colab or using the GitHub upload feature.

## Practice workflow
1. Create a branch
2. Edit a notebook
3. Commit the notebook
4. Push the branch
5. Open a pull request
6. Merge the change

## Run locally
If you want to run the notebooks locally, install:

```bash
pip install jupyter pandas matplotlib
```
